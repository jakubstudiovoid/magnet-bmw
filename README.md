# MAGNET BMW

Prémiový web autoservisu MAGNET BMW v Jablonci nad Nisou.

## Spuštění

```bash
npm install
npm run dev
```

Vývojový server běží na http://127.0.0.1:8080.

```bash
npm run typecheck
npm run build
npm run preview
```

## Nasazení

Repozitář jde nasadit na Vercel. Build příkaz je `npm run build`.
